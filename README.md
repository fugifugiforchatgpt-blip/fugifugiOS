🖥️ Fugi_fugi OS
Fugi_fugi OS — это графическая операционная система, написанная на Python с использованием Tkinter. Она включает рабочий стол, панель задач, меню Пуск и множество встроенных приложений — от калькулятора до нейросетей.

🎯 Возможности
🖥️ Рабочий стол и интерфейс
Рабочий стол с иконками приложений

Панель задач с кнопкой «Пуск» и часами

Календарь по клику на часы

Светлая, тёмная и неоновая темы (5 цветов неона)

Полноэкранный режим

📂 Файловый менеджер
Просмотр папок и файлов

Открытие .txt, .png, .mp3

Копирование, вырезание, вставка, удаление, переименование

Создание папок, текстовых файлов, рисунков, загрузка музыки

📝 Приложения
Калькулятор — базовые операции

Блокнот — сохранение в notes.txt

Рисовалка — кисть, ластик, выбор цвета, сохранение в PNG

Файловый менеджер — управление файлами

Настройки — смена фона, темы, неон-режим, пропуск BIOS

🎮 Игры
Змейка (одиночная и с ИИ на 3 уровнях сложности)

Сапёр (9×9, 10 мин)

Тетрис — классика с превью следующей фигуры

🎵 Мультимедиа
Музыкальный плеер — MP3 с прогресс-баром и громкостью

🧠 Искусственный интеллект
GigaChat Ассистент — текстовый ИИ-помощник (требуется API-ключ)

Фуги Фуги ИИ — нейросеть для анализа тональности текста (собственная, обучена на 200 000 предложений!)

ФФGPT — чат-бот с генерацией изображений по тексту (объекты, еда, животные)

🛠️ Системные утилиты
Очистка системы — удаление временных файлов

Диспетчер задач — список открытых окон, статистика CPU и RAM

Голосовой помощник — управление ОС голосом (распознавание + GigaChat)

👤 Пользователи
Вход по паролю (пользователи хранятся в users.json)

Хеширование паролей (SHA-256)

🚀 Установка и запуск
1. Клонируй репозиторий
bash
git clone https://github.com/твой_ник/Fugi_Fugi_OS.git
cd Fugi_Fugi_OS
2. Установи зависимости
bash
pip install -r requirements.txt
3. Настрой GigaChat (опционально)
Для работы голосового помощника и ассистента нужен ключ GigaChat.

Открой файл config.py

Вставь свой ключ вместо "вставь свой код сюда"

Сохрани файл

4. Запусти ОС
bash
python main.py
📦 Требования
Python 3.10+

Tkinter (встроен в Python)
